第一篇博客，想了很久该写点什么。技术文还没攒够底气，牢骚又怕第一篇就劝退路人，干脆诚实地介绍一下我自己——顺便，做一次迟到的自我接受。

## 我是谁

贺俊超，河南许昌人，郑州大学物联网工程专业，大四，秋招进行时。

主攻 Java 后端，业余折腾 Agent。简历上写的是「熟悉 JVM 内存模型与常见 GC 策略」，翻译成人话就是：背过，调过，偶尔还在深夜被 OOM 教育过。

## 一些平平无奇的数字

GPA 3.2，专业前 50%。英语只有 CET4，六级还在排队。最拿得出手的奖项，是 2023 级 ACM 院赛一等奖——注意，是院赛，不是校赛，更不是省赛。

以前我不太好意思提这些。写简历的时候，总忍不住把「前 50%」往「前 30%」的方向幻想，把「院赛」在心里悄悄升个级。后来想通了：数字就是数字，它们不丢人。起点的确普通，但普通不是终点，更不是罪过。

## 专业不对口，那就自己补

学的物联网工程，写的却是 Java 后端——这门手艺基本是课外自己一点点攒出来的。

这两年做了两个项目：一个本地生活服务平台，把缓存穿透/击穿/雪崩的三级防护、Redisson 加 Lua 的秒杀扣减、RabbitMQ 的可靠性投递都趟了一遍。首页 P99 从 500ms+ 压到 95ms 的那个下午，是我最近最有成就感的时刻之一。另一个是仿 12306 的购票系统，第一次认真面对分库分表、沿途区间扣减库存这种书本上一笔带过、实际做起来全是坑的问题。顺带用 LangChain4j 折了个 RAG 智能客服进去，从此对「Agent 到底能帮人干多少活」这件事上了头。

今年四月起在泰康保险实习，在理赔中台组写 Java，第一次碰到了真实世界的代码。也第一次知道，工业级的代码里，日志、告警、幂等这些「不起眼」的东西，比任何炫技都重要。

## 关于焦虑

秋招季刷面经，看到别人聊 AQS 源码如数家珍、手撕算法面不改色，说不慌是假的。

但慌完之后我发现，我能做的也只有：把眼前这道题弄懂，把这个项目的坑填上，把明天的八股背完。焦虑不会因为我慌张就多给一个 offer，但一道一道刷下去的题会。

所以我接受了：我是个普通人，反应不算最快，起点不算最高。但普通人有普通人的走法——每天走一点，回头看的时候，其实已经离出发的地方很远了。

## 这个博客会写什么

技术分享（Java 后端、Agent、踩坑复盘），牢骚（秋招的、面试的、生活的），日记（平凡的、碎片的）。

就像这个博客的名字：赛博自留地。不追热点，不看数据，想种什么种什么。

如果你也是一个普通人，欢迎常来，我们一起种地。
