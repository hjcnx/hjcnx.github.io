白天造轮子，晚上抬头看月亮。我是 Hjc，一名独立开发者。

这座「赛博自留地」用来存放我的技术笔记、设计实验，和一些不合时宜的念头。取名自留地，是因为它不追热点、不赶算法——只种自己想种的东西，安静，但一直在生长。

## 这里会写什么

- **前端与设计工程**：CSS 架构、动效、设计系统的落地笔记
- **工具与效率**：命令行、编辑器、自动化脚本
- **深夜随笔**：读书、通勤、城市夜行的一些观察

## 关于这个站点

站点采用自研的「Nocturne Glassmorphism / 夜航玻璃拟态」设计系统：无色玻璃覆于深夜场景之上，颜色由场景承载，玻璃只负责借光。基于 Hexo 构建，部署在 GitHub Pages。

如果你想交流，欢迎通过页脚的 GitHub 或邮箱找到我。
